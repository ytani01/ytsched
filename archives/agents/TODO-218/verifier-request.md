- 画面サイズ 412x915。`?date=2027-04-26` を開き、ミニカレンダーが出ている状態で
  `evaluate` でまとめて読み出す:
  1. 2027/05 のミニカレンダーの `td[data-date="2027-04-29"]`（前の月の日・休日）、
     `2027-04-30`（前の月の日・平日）、2027/04 のミニカレンダーの
     `td[data-date="2027-05-01"]`（土）・`2027-05-02`（日）の
     `className` と `getComputedStyle().backgroundColor` / `color`
  2. 同じセルの、その月側の表示（2027/04 の `2027-04-29`、2027/05 の
     `2027-05-01`）の `backgroundColor` と並べ、前後の月の日と同じ背景色か
  3. `2027-04-29` のセル（両方）に `.my-mini-cal-dot` が無いこと、
     `2027-04-16` のセルにはあること
