## 確かめてほしいこと

   （`mise run upgradeproject` は走らせない）
2. **実際にブラウザで動くか。** アプリを起動し（`--datadir` は必ず
   一時ディレクトリ）、ゲージの帯のいろいろな位置をクリックして、
   針の位置と、移った週が合っているか。少なくとも中央付近・右寄り・
   左寄り・右端・左端を見る
3. **既存の操作が壊れていないか。** ゲージの上から横へドラッグしたときに
   今までどおり週が送れるか、日付セルやボタンのクリックが今までどおりか

   位置に針が来るか（1 週間ぶんの丸めのぶんはずれてよい）

   （帯全体が黄色くなる。これが目障りでないか、意見を書く）
