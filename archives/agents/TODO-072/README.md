関数 1 つ分の分岐で、設計の判断はほとんど無かった。実装まで分けると
仕様を書き写す手間のほうが大きいので、実装は main が持った。

**確認は分けた。** コードやファイルを変える項目では、規模によらず確認を
別の担当にする決まり（`~/.claude/CLAUDE.md`）。今回はそれに加えて、
確かめてほしいことがはっきりしていた。

- サーバ側（Python）と JavaScript 側で、同じ規則を 2 回書いている。
  食い違うと針が動く前後で文字が変わる。main も 3201 通りで突き合わせた
  が、**同じ思い込みで両方書いた本人が確かめても意味が薄い**ので、
  独立にやり直させた
- ブラウザテストと実アプリの起動は、手順がはっきりしていて判断が要らない
