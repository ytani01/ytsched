# TODO-052 wording 報告

## 対象

`git diff TODO.md`（作業ツリー、ステージ前）で見える差分のみ。
このコミットに入るのは `TODO.md` だけ（依頼どおり）。

- 先頭の「残っている項目」「番号は」の行の書き換え
- 新設した「## TODO-052. TODO 項目を足す作業を、スキルかスクリプトに
  できないか検討する」の節（見込み表・チェックリスト・きっかけ）

## 拾った語と前例

前例の件数が少ない順。

### スキル（0 件・前例なし）

- 出てくる箇所: 見出し「…スキルかスクリプトにできないか検討する」、
  本文「スキルにするか、スクリプトにするか、いまのままにするかを
  決める」
- `git grep -cF スキル HEAD -- '*.md'`: 0 件（合計）
- 見立て: Claude Code の「Skill」機能を指す一般的な IT 用語で、
  この文脈では固有名詞的に使われている。リポジトリ内では初出だが、
  CLAUDE.md 側にも Skill 機能への言及（`show-image` skill）があり、
  一般に通用する語だと判断できる。造語ではなく、単にこの `TODO.md`
  で初めて言及しただけと見る

### いまのまま（0 件・前例なし）

- 出てくる箇所: 「いまのままにするかを決める」
- `git grep -cF いまのまま HEAD -- '*.md'`: 0 件
- 見立て: 普通の日本語の言い回し。造語ではないと判断できる

### 採り違い（0 件・前例なし、複合語）

- 出てくる箇所: 「番号の採り違い、目次の行の直し忘れ」
- `git grep -cF 採り違い HEAD -- '*.md'`: 0 件
- 見立て: 「取り違え」の表記ゆれ（「採り」）。過去（TODO-035）には
  「取り違える」の表記で使われている（`archives/agents/TODO-035/
  wording-report.md`）。同じ語の異表記であり、新しい造語には
  見えない。ただし表記が「採り」で揺れている点は気になる

### 直し忘れ（3 件・前例あり）

- 出てくる箇所: 「抜けやすい（番号の採り違い、目次の行の直し忘れ）」
- `git grep -cF 直し忘れ HEAD -- '*.md'`: 3 件
  （`archives/agents/TODO-035/README.md`、`wording-report.md`、
  `writer-request.md`）
- 見立て: 前例あり。問題なし

## 判断できない語は無かった

「残っている項目」「番号は」「手順」はいずれも前例が複数あり、
かつ普通の語なので候補から外した。
