# TODO-062・TODO-063 の文書確認（wording）

対象: `TODO.md` の追加分（`git diff TODO.md`）のみ。TODO-062・TODO-063 の
2 節。ほかの `.md` はこのコミットに入らない。

## 前例の無い語

前例の件数が少ない順（0 件はすべて同列）。

### 指に付いて（くる）

- 出てくる箇所:
  - TODO-062 見出し「スワイプが、60px 動くまで指に付いてこないのを直す」
  - 「そのぶん**指を 60px 動かすまで画面はまったく動かず**」
  - 「指に付いて動く感じがしない」
  - 確かめ方「実機（スマホ）で、指の動きに合わせて隣の週が見えてくること」
- `git grep -cF "指に付いて" HEAD -- '*.md'`: 前例なし
- 見立て: 「追従」の言い換えとして使っている。指に触覚的に付随して動く、
  という感覚を表す普通の言い回しに見えるが、この文書で初めて使われた
  表現。一般に通用するかは判断できない

### 取り合い

- 出てくる箇所: 「**縦スクロールとの取り合いが崩れないか。** 閾値を
  下げると、縦にスクロールしたいだけの指で週が動きだす」
- `git grep -cF "取り合い" HEAD -- '*.md'`: 前例なし
- 見立て: 「競合」「干渉」に近い意味で使っている。日常語ではあるが、
  この文脈（UI のジェスチャー同士がぶつかる話）での言い換えとしては
  このリポジトリで初出。一般語ではあるので造語というより言い回しの
  選択の問題に見える

### 滑る

- 出てくる箇所: 「指を離したあとの動き（0.2 秒で隣の週まで滑る。
  `slideWeekWrap()`）」
- `git grep -cF "滑る" HEAD -- '*.md'`: 前例なし
- 見立て: 普通の動詞。アニメーションの動きを表す表現として自然で、
  造語ではなさそう。ただし前例が無いことは事実として挙げる
