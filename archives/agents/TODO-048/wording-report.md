# TODO-048 wording 報告（書き直し版）

対象: `TODO.md` の差分（`git diff TODO.md`）。TODO-048 節を「Font Awesome
の SVG を使う」案から「22 個すべてを自作の線画アイコンにする」案へ
全面的に書き直した部分（19〜122 行目あたり）。

この節は一度 wording 済み（`archives/agents/TODO-048/wording-report.md`
の旧版、いまは本報告で上書き）だが、その回は Font Awesome の SVG を
そのまま使う案が対象で、今回とは内容が別物。改めて全体を読み直した。

前例の件数は `git grep -cF <語> HEAD -- '*.md'` を合計したもの
（`HEAD` は書き直し前の `TODO.md` を含む。つまり旧版の TODO-048 節や、
旧版に対する wording 報告も前例として数に入る）。

## 前例なしの語

- **図案**
  - 箇所: 「図案も写さない」「図案そのものは構わないが」「図案が通れば
    差し替えに進む」
  - 前例: 0 件
  - 見立て: 「デザイン」「絵柄」の意味で一般に使われる日本語で、造語には
    見えない。判断できるほうの語

- **線画**
  - 箇所: 「線画で描き起こす」「線画にする」
  - 前例: 0 件
  - 見立て: イラストや漫画の分野で普通に使う語（line art / line drawing
    の訳語）。造語ではないと思う

- **描き起こす**
  - 箇所: 「22 種類のアイコンを、線画で描き起こす」
  - 前例: 0 件
  - 見立て: 「新たに描く」の意味で一般的な言い方（「描き下ろす」に近い）。
    造語ではないと思う

- **太さ**
  - 箇所: 「太さ 2 の線で描く」「線が太くなりすぎる」「線の太さを下げる」
  - 前例: 0 件
  - 見立て: ごく普通の日本語（「厚さ」と並ぶ基礎語）。前例が無いのは
    単にこれまで太さの話が出てこなかっただけで、造語ではない

- **幾何的**
  - 箇所: 「幾何的に引き直す」
  - 前例: 0 件
  - 見立て: 「幾何学的」の縮めた形。一般にも使われるが、「幾何学的」の
    ほうが定着した言い方に見える。**言い換えを検討してよいかもしれない**
    （このリポジトリだけの言い換えではないが、やや口語的）

- **引き直す**
  - 箇所: 「幾何的に引き直す」
  - 前例: 0 件
  - 見立て: 「線を引き直す」の意味で、図形を描く文脈では自然な言い方。
    造語ではないと思う

- **輪郭だけ描く**（「輪郭」単体は前例あり、後述）
  - 箇所: 「外形を同じにして、輪郭だけ描くか中を塗るかで分ける」
  - 前例: 「輪郭だけ描く」という言い回しそのものは 0 件（「輪郭」単体は

  - 見立て: 言い回しとしては「輪郭」を素直に使っているだけで、新しい

- **承認を取る**

    進む」
  - 前例: 0 件
  - 見立て: 一般的な言い回し。造語ではない

- **行の詰まり具合**
  - 箇所: 「大きさ・縦位置・行の詰まり具合が崩れていないことを…確かめる」
    （2 か所）
