## 前例の無い語

前例なし（`git grep -cF <語> HEAD -- '*.md'` が 0 件）の候補を洗ったが、
名詞・用語として独立して呼び名になっているものは見つからなかった。
0 件になったのは次のような**文の断片**で、いずれも一般的な言い回しの
一部を切り出しただけであり、造語ではないと見立てる（見出し・専門用語
としての単位ではないため、そもそも「語」の候補として扱うべきか怪しい）。

- 「反対側を足す」（「端を捨てて反対側を足す処理が要る」の一部）
- 「指を離して」（「指を離して切り替わりが決まってから」の一部）
- 「切り替わりが決まって」（同上）
- 「追従している間」（「追従している間も動かすか」の一部）
- 「済んでから着手する」（「TODO-054 が済んでから着手する」の一部）
- 「ページごと差し替えている」（「`doGet()` でページごと差し替えている」の一部）
- 「3 週分を横に並べ」（「3 週分を横に並べ、指の動きに合わせて」の一部）

これらは文の一部を機械的に切っただけで、独立した術語として使われては
いない（例えば「反対側を足す」は普通の日本語の組み合わせであって、
このリポジトリ固有の呼び名ではない）。**見立て: 造語ではない。**
