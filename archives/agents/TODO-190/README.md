# TODO-190 の分担

外部の事実（Sonnet 5 の単価）を確かめて、`CLAUDE.md` の記述を直すだけの項目。
コードは 1 行も変えていない。

| 担当 | モデル | 依頼したこと |
|------|--------|--------------|
| main | Opus 5 / effort high | 単価の確認、`CLAUDE.md` と `token-usage.py` のコメントの修正、TODO と archives の記述 |
| verifier | Sonnet 5 / effort medium | 公式のドキュメントを独立に引き直しての単価の裏取り、直した記述との突き合わせ |

## この分担にした理由

- **implementer は立てなかった。** 変更は `.md` 1 か所と Python のコメント
  1 か所で、挙動は変わらない
- **reviewer は立てなかった。** 分岐も条件式も変わらない
- **verifier は分けた。** 文書だけの項目なので `CLAUDE.md` の例外
  （書式が揃っているかしか見ないなら main でよい）に当たりそうだが、
  ここで確かめるのは書式ではなく**外部の事実**で、間違えると全項目の
  概算料金の見方が狂う。公式のドキュメントを独立に引き直させる価値があると
  判断した
- **verifier のモデルは定義のまま。** `sonnet` / `effort: medium`。
  ドキュメントを引いて表の数字と突き合わせる作業で、判断は要らないが、
  読み違えると結論が逆になるので下げなかった
