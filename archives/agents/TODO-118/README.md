# TODO-118 の分担

| 担当 | 役割 |
| --- | --- |
| main | 現行の実装と実データを調べ、Obsidian 側の制約を確かめて、評価報告書を書く |
| verifier | 報告書に書いた事実（コードの場所と挙動、実データの数字、テストと文書の数）が実際と合っているかを確かめる |

コードは変えず、`docs/` に評価報告書を 1 つ足すだけの項目。書く中身は
「現行の作りをどう読むか」の判断が中心なので、調べるところから書くところ
までを main が続けて行った。

ただし報告書は、読む人が実装するかどうかを決める材料になる。**数字や
コードの挙動が間違っていると判断を誤らせる**ので、事実の確認だけを
verifier に分けた。実際に 2 か所（テストの数え方、`.jsonl` の出現箇所の
数）の食い違いが出て、報告書を直した。

各担当の報告は、このディレクトリに置く。
