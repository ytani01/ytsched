# TODO-101 の分担

## 誰にどこを

| 担当 | 範囲 | 報告 |
|---|---|---|
| main | `edit.html` と `my.css` の実装 | — |
| verifier | lint・型・`pytest`・アプリ起動と画面の確認 | [verifier-report.md](verifier-report.md) |
| wording | コミットに入る `.md` の前例の無い語 | [wording-report.md](wording-report.md) |

## この分担にした理由

- テンプレートと CSS の 2 ファイルだけで、ロジックは変わらないので、
  実装は main が持った（`~/.claude/CLAUDE.md` の「複数のファイルに
  またがる」の目安には届かない）。
- 見た目を変える項目で、テストでは崩れを拾えないため、確認は
  verifier に分けた（規模によらず確認は分ける）。実際に画面を撮って
  もらう手順があるので、main で済ませずに分ける側に当たる。
- 挙動や分岐は変わらないので reviewer は入れていない
  （TODO-017 の基準）。
- `.md` が入るコミットなので wording を立てた（CLAUDE.md）。

## main が単独で決めたこと

- 新規作成のときに複製の枠を空の `.col-2` で埋めていたのをやめ、
  枠ごと出さないようにした。センタリングでは空の枠が中央をずらす。
- 間隔は最初 `gap: 2rem` にした。verifier からも「見た目やや広めだが
  崩れてはいない」という報告があり、利用者の「もっと中央にかためて」で
  `0.75rem` へ詰めた。
