# TODO-075 wording 報告（1回目）

対象: `TODO.md` の新しい節「## TODO-075. 文書と実装のズレを直す」
（先頭の見出しと「残っている項目」の行の書き換えを含む）。`git diff TODO.md`
で見た差分のみを対象にした。

## 前例の無い語

### 「追いつ」（「実装に追いついていなかった」）

- 出てくる箇所: 「文書を通して読み、実装と突き合わせたところ、次の 8 件が
  実装に追いついていなかった。」
- `git grep -cF` の件数: 前例なし
- 見立て: 一般の日本語として自然な言い回し（「文書が実装に追いつく」）で、
  このリポジトリ特有の言い換えには見えない。造語というより通常語の
  組み合わせ。判断は main に委ねる

## 前例はあるが目に留まった語（参考）

以下は `git grep` で HEAD に前例があったので「前例の無い語」には数えて
いないが、念のため確認した経緯を記す。

- 「ズレ」（見出し・冒頭） 前例あり（複数ファイル）
- 「突き合わせ」 前例あり（多数）
- 「週送り」 前例あり（多数、直近の TODO-074 でも使用）
- 「旧形式」 前例あり（`docs/data-format.md` ほか）
- 「実データ」 前例あり（`CLAUDE.md` ほか多数）
- 「無限スクロール」単体では前例なしだが、この節では「無限にスクロール」
  （README.md に既にある表現の引用）として使われており、新しい言い換え
  ではない
