## 前例の無い語

件数の少ない順。

### 恒等式

- 箇所: `reviewer-report.md`「`(1 - wday) + 7` は代数的に旧コードの
  `8 - wday` と完全に一致する」の少し後、「次へ送る側は……恒等式なので
  確認するまでもなく保証されている」
- `git grep` の件数: 前例なし
- 見立て: 数学用語としては一般的だが、このリポジトリでは初出。
  文脈から意味は通るので問題は薄いと思うが、判断は main に委ねる

### 代数的

- 箇所: `reviewer-report.md`「`(1 - wday) + 7` は代数的に旧コードの
  `8 - wday` と完全に一致する」
- `git grep` の件数: 前例なし
- 見立て: 一般的な語で、造語というより通常の言い回し。問題は薄いと思う

### 滑らせる先

- 箇所: `TODO-063.md` の見出し「滑らせる先とのずれも、ついでに消えた」
- `git grep` の件数: 前例なし（近い語「滑らせる」「滑らせて」は
  TODO-057・TODO-049 に前例あり）
- 見立て: 「滑らせる」自体は既出だが、「滑らせる先」という名詞化した
  言い方はここが初出。このリポジトリ限定の言い換えに見える。
  「スライドで見せる週」のような言い方との違いを main に確認してほしい

### 場合分け

- 箇所: `TODO-063.md`「月曜かどうかの場合分けが要らなくなり、分岐ごと
  消えた」、`request.md` にも同旨の文
- `git grep` の件数: 前例なし
- 見立て: 一般的なプログラミング用語（条件分岐の意味）。造語ではなさそう

### 対応不要

- 箇所: `reviewer-report.md`「今回の変更が持ち込んだ問題ではない。
  念のため書いておくだけで、対応不要と考える」の直前の見出し
  「確信度の低い所感（参考。指摘ではない）」の本文中
- `git grep` の件数: 前例なし
- 見立て: ごく普通の日本語（漢語の組み合わせ）。問題は薄いと思う

### shiftDays

- 箇所: `reviewer-report.md`「`shiftDays()`（`d.setDate(d.getDate() +
  days)`）に渡すだけで」
- `git grep` の件数: 前例なし
- 見立て: `my.js` 内の関数名（コード識別子）。造語というより、この
  関数について文書で触れたのが今回が初めてというだけに見える

## まとめ

前例なしの語数: **6 語**（恒等式・代数的・滑らせる先・場合分け・
対応不要・shiftDays）。目安の「1〜3 語なら問題なさそう」よりやや多いが、
「足場」のように意味が別物へすり替わっている語は無く、いずれも文脈通りの
一般語・コード識別子に見える。特に判断してほしいのは「滑らせる先」
（名詞化した言い換えがこの文書だけのものかどうか）。
