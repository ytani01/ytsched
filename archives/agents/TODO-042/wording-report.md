## 対象

`git diff TODO.md` の差分（冒頭の「残っている項目」行と、「## TODO-042.
左端のゲージの針(▶)の位置が内側にずれている。」の節）。

## 前例の無い語

### 基準線

- 箇所: 「基準線の `#gage_r_base`（`fa-grip-lines fa-xs`、幅 0.875em）も
  同じ理由で約 2.5px ずれている。」
- `git grep -cF 基準線 HEAD -- '*.md'`: 前例なし
- 見立て: 「目盛りの基準となる線」の意味で一般にも通用しそうな語。
  `#gage_r_base` という要素名の説明として自然で、このリポジトリ独自の
  言い換えには見えない。ただし初出であることは確か

### 横位置

- 箇所: 「針（▶）は `main.html` の `#gage_r`（...）で、横位置は `my.css`
  の `.my-gage-r { left: 1px; }` で決めている（縦位置だけ `my.js` が
  書き換える）。」
- `git grep -cF 横位置 HEAD -- '*.md'`: 前例なし
- 見立て: 一般的な語（CSS の `left` に対応する位置の呼び方として自然）。
  造語には見えない

### 縦位置

- 箇所: 上記と同じ文中「縦位置だけ `my.js` が書き換える」
- `git grep -cF 縦位置 HEAD -- '*.md'`: 前例なし
- 見立て: 「横位置」と対になる一般的な語。造語には見えない
