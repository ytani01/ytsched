# wording への依頼（2 回目・TODO-042 を済ませるコミット）

1 回目（項目を立てるコミット）の報告は同じディレクトリの
`wording-report.md` にある。**今回はその続き**なので、報告は
`wording-report.md` の末尾に

```
---

## 2 回目（済ませるコミット）
```

という節を作って追記すること（新しいファイルを作らない）。

## 見てほしいファイル

このコミットに入る `.md` は次の 2 つ。

- `archives/todo/TODO-042. 左端のゲージの針の位置がずれているのを直す.md`（新規）
- `TODO.md`（TODO-042 の節を archives へ移し、目次に足した）

加えて、**1 回のコミットに入りそこねた次の 2 つも見てほしい**。
これらは実装のコミット（`7a2c8f1`）で既に入っており、wording を
通していない。

- `archives/agents/TODO-042/verifier-report.md`
- `archives/agents/TODO-042/README.md`

## やること

このリポジトリに前例の無い語を挙げる。候補は十数語に絞り、それぞれに
見立て（一般に通用する専門用語か、造語に近いか、既にある語で置き換え
られるか）を添える。**文書は直さない。** 決めるのは main。

`TODO-042` は Font Awesome のアイコンの位置の話なので、CSS・フォントの
専門用語（`left side bearing`、`グリフ`、`字面` など）が初出で出てくる。
「前例なし ＝ 造語」ではないので、そこは見立てで分けてほしい。
