# TODO-002 のサブエージェント編成

**現行の設定ではない。** 使い回すときは `.claude/agents/` へ複製すること
（Claude Code は起動時にしか読まないので、置いたら再起動が要る）。

この回は `.claude/agents/` に置かず、Agent ツールへ直接プロンプトを渡して
起動した。ここに置いた 2 ファイルは、そのとき渡した内容を
エージェント定義の形に整えたもの。

対応する項目: [TODO-002. uv プロジェクトへの移行](../../todo/TODO-002.%20uv%20プロジェクトへの移行.md)

## 分担

| 名前 | モデル / effort | 担当 |
|---|---|---|
| [migrator](migrator.md) | Opus 5 / effort medium | 構成移行の実装いっさい（ファイル移動、`pyproject.toml`、`__version__`、webroot のパス解決） |
| [verifier](verifier.md) | Sonnet 5 / effort medium | `uv sync` と `uv run ytsched webapp` の起動確認。**コードは直さず報告のみ** |

main（管理者）は依頼と確認に徹し、成果物のレビュー・`TODO.md` の更新・
コミットを受け持った。

## この分担にした理由

- 判断が要るところ（webroot のパス解決、hatch-vcs の版数の出方、
  パッケージデータの含め方）が 1 か所に固まっていたので、
  実装を分割せず Opus 1 人にまとめた。分けると同じ文脈を 2 回読ませることになる
- 起動確認は手順が決まっており判断が要らないので Sonnet に回した。
  実装者と確認者を分けることで、「動くはず」で済ませずに実際に叩く担当ができる
- `verifier` には**編集を禁じた**。不具合を見つけても直させず main へ報告させ、
  直すかどうかは管理者が判断する形にした
