# TODO-172 の分担

| 担当 | 誰が | 何を |
|------|------|------|
| 実装 | main | `trash.html` と `my.css` の変更、画面を撮っての見た目の調整 |
| 確認 | verifier | lint・型チェック・テスト、アプリを起動しての動作確認 |

## この分担にした理由

変更は 2 ファイルで、どちらも見た目だけ。実装を分けるほどの規模では
なく、**撮って見て直すという繰り返しが要る**ので main が持った
（依頼と報告のやり取りを挟むと、この繰り返しの回数だけ費用がかかる）。

一方、**確認は分けた。** 見た目の変更でも、テンプレートの構造を
変えている（削除日時を枠の中へ移した）ので、復活・一括削除といった
既存の操作が壊れていないかを別の目で見る必要がある。
