  `#trash` アイコンの全消去ボタンを表示する。ボタンの `aria-label` は
  「空にする」で、既存の `data-confirm` も維持されている。

  それぞれの条件をテストで確認している。

  末尾の `/` を含むため、週間表示の URL になる。POST のテストもこの URL と
  ゴミ箱の空化を確認している。
- 旧末尾ボタンの HTML と `my-trash-clear-row` の CSS は削除済みで、残る
  `my-trash-clear` のスタイルはヘッダー用のアイコンボタンに使われている。
