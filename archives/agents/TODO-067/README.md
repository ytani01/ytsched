# TODO-067 の分担

| 担当 | 何を見たか | 報告 |
|------|-----------|------|
| main | 実装（CSS・テンプレート）と、位置の測定 | — |
| verifier | テスト・lint の実行と、実際の画面・要素の位置の確認 | [verifier-report.md](verifier-report.md) |
| wording | コミットに入る `.md` の、前例の無い語 | [wording-report.md](wording-report.md) |

## この分担にした理由

- **実装は main で足りる。** 直すのは CSS 2 か所とテンプレート 1 か所で、
  原因は立てた時点で 3 つに絞ってあった（`docs(todo): TODO-067 を精査して、
  直すところを 3 つに整理する`）。設計を分けて考えるところが無い
- **確認は分けた。** 見た目の変更はテストが通ることでは確かめられない
  （TODO-042・TODO-043・TODO-045・TODO-066 と同じ）。とくに今回は
  `align-middle` を効くようにしたことで**フッター以外の見た目も変わりうる**
  ので、そこを別の目で見てもらう必要がある
- **reviewer は入れていない。** Python のコードは 1 行も触っておらず、
  分岐や挙動の判断は変えていない

## 効いたところ

**verifier を分けた効果がそのまま出た項目。** main はフッター以外の
2 画面を撮り比べて「変わっていない」と判断したが、verifier が変更前の
コードを別ポートで起動して `getBoundingClientRect()` と画素差分で比べ、
2.77px と 4.5px のずれを見つけた。**画面を並べて目で見るだけでは、
数 px のずれは分からない。**
