# TODO-103 verifier への依頼

TODO-103（月間ミニカレンダー）の実装が実際に動くかを確かめる。
**コードは直さない。** 見つけたことは報告するだけ。

先に読むもの:

- `archives/agents/TODO-103/implementer-request.md`（決めた設計）
- `archives/agents/TODO-103/implementer-report.md`（やったこと）
- `TODO.md` の TODO-103

## 確かめること

1. `mise run lint` / `mise run typecheck` / `uv run pytest` を走らせ、
   出力をそのまま報告する。落ちたテストがあれば、この変更が原因か
   （`git stash` して外した状態でも落ちるか）まで見る
2. 一時ディレクトリを `--datadir` に指定してアプリを起動し、実際の画面で
   次を確かめる。データは自分で何日分か作って置くこと
   - 週間表示の日曜日の下に、2 ヶ月分のミニカレンダーが横に並ぶ
   - 出ている月が「表示中の週の月曜が含まれる月」と「その翌月」である
   - 予定がある日にドットが出て、無い日には出ない
   - 日付をタップすると、その日へ移る（読み込んだ範囲の中の日と、
     範囲の外の日の両方を試す。後者はページの読み直しになる）
   - 前後の月の埋めセル（薄い数字）はタップしても動かない
   - 今日と、表示中の週の 7 日が見分けられる
   - 週送り（◀▶・スワイプ・キーの←→）で月が切り替わる。月をまたぐ
     ときに正しい 2 ヶ月になる
   - 検索したときはミニカレンダーが出ない
   - 幅 412px で、はみ出したり横スクロールが出たりしない
3. 画面を撮って報告に貼る（`tools/screenshot.py` がある）

## 報告

`archives/agents/TODO-103/verifier-report.md` に書く。返事は
「終わったか・報告ファイルのパス・判断が要る点」の 5 行以内で。
