# TODO-176 の分担

見た目の調整。`my.css` 1 ファイルの想定で始めたが、着手後に利用者の
指示で範囲が広がり（`<main>` の背景、ゴミ箱、地の色の濃さ）、最終的に
4 ファイルにまたがった。

## 実装

- **implementer** — 最初の `my.css` の変更（ミニカレンダー・月間表示の
  背景をグレーに、表を白いカードに）。
  → [implementer-report.md](implementer-report.md)
- **main** — 着手後に足りないと分かったぶんを直接実装した。
  実装を分けるほどの規模ではなく（値の調整と 1 行の JS）、利用者と
  対話しながら詰める必要があったため:
  - `main.html` の `<main>` インライン背景 `#FFF` を撤去（白帯の一因）
  - `#main` に地の色を持たせ、色を `--my-cal-ground` の CSS 変数へ集約
  - `main-page.js` `onloadHdr()` の `body_h < win_h` 分岐で `#main` を
    画面の高さちょうどまで伸ばす（フッターとの間の白帯対策。
    `min-height: 100vh` を CSS へ直接入れるとスクロール位置合わせの分岐が
    反転して退行したため、この形にした）
  - ゴミ箱 `.my-trash-main` を、編集画面と共用の `.my-edit-body` (#EEE) から
    切り離して `--my-cal-ground` に
  - 地の色を `#F0F0F0` → `#E8E8E8` → `#E0E0E0` → `#D8D8D8` と調整
    （予定ブロックの #EEE より濃くして、ブロックがカードに見えるように
    する。最終値 `#D8D8D8` は利用者が選んだ）
