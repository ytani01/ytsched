## きっかけ

ゴミ箱の表示が見にくい、という話から。一時ディレクトリにテストデータを
作って画面を撮り、気になった点を挙げて、直すものを選んでもらった。

- 削除日時（`版 2 ・ 2026-09-02 09:18:22 に削除`）が予定の枠の外に
  あり、上下どちらの予定のものか紛らわしい
- 「同じ予定の内容が N 件」のグループが、見出しの文字だけでどこまでか
  分からない
- チェックボックスが小さく、800px では右端に離れていて押しにくい

**削除日時を短く（年・秒を省く）するのは見送った。** 挙げたが選ばれ
なかった。

## やったこと

`trash.html` と `my.css` の 2 ファイル。

- **削除日時を予定の枠の中へ移した。** `.my-date-block`（12 列
  グリッド）の外にあった `div` を中へ入れ、`.my-trash-trashed-at` で
  `grid-column: span 12` の右寄せにした。1 行目で 12 列を使い切って
  いるので、行の指定をしなくても 2 行目へ回る。これで枠が 1 件の
  まとまりになった
- **同じ予定のグループを帯でくくった。** 2 件以上のグループにだけ
  `.my-trash-group-multi` を付け、背景 `#CCC` と左の縦線
  （4px `#888`）で範囲を見せる。1 件だけのグループには付けない
- **チェックボックスを 1.25rem に大きくし、`.my-trash-actions` を
  `justify-content: center` にして復活ボタンの隣へ寄せた。**
  800px でも右端まで離れない

グループの余白の付け方は、撮って見ながら 3 回変えた。左に縦線と
パディングを足すと予定の列がそのぶん狭くなり、412px で長いタイトルが
折り返す。いったん縦線をやめて背景の色だけにし、次に右側を
`.my-trash-main` のパディングのぶん外へ広げて幅を取り返したが、
**「縦線もあったほうがいい」「右端は少し削られてもいい」** という
返事で、左の縦線と左右の余白を持つ形に落ち着いた。412px で折り返す
ことはあるが、まとまりが見えるほうを取っている。

## テスト

verifier の報告は
[`archives/agents/TODO-172/verifier-report.md`](../agents/TODO-172/verifier-report.md)。

- `mise run lint` / `mise run typecheck` / `mise run test`（664 件）が
  すべて通った
- 一時ディレクトリに同じ UUID・版違いを含む `trash.jsonl` を用意して
  アプリを起動し、`/ytsched/trash` が HTTP 200 で出ること、
  テンプレートの `{{ }}` が展開されていることを確認
- 復活（`cmd=restore`）で `sde_id` の版が 1 つ増え、タイトルに
  `(復活)` が付いた行が追加されることを確認
- 一括削除（`cmd=delete_many`）で件数が減り、0 件になると
  「ゴミ箱は空です」が出て、ヘッダーのチェックボックスと削除ボタンに
  `disabled` が付くことを確認
- 見た目は `mise run shot` で 412px と 800px を撮って確かめた

グループの縦線を戻したのは verifier の確認が終わったあとなので、
そのあと `mise run lint`（prettier を含む）だけ走らせ直した。
背景色と枠線の指定だけで、動きには関わらない。
