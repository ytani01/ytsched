## きっかけ

2026-08-26 に、利用者から「編集画面からブラウザの戻るで週表示へ戻ると、
スピナーが出たままになる」と挙がった。項目には「TODO-065 に入れられるなら
TODO-065 で対応」と書いてあった。

## 原因

スピナーを消しているのは各ページの `load` ハンドラ（`onloadHdr()`）だけ
だった。**bfcache（戻る/進むでページごと復元されるキャッシュ）から復元
されたときは `load` が起きない**ので、`doGet()` が出したスピナーが
そのまま残る。

## やったこと

`src/ytsched/webroot/static/js/my.js` に `pageshow` の listener を足した
（TODO-065 のコミット `9f2aa79` に含まれる）。

- `event.persisted` が真、つまり bfcache から復元されたときだけスピナーを消す
- 偽なら即 return するので、通常の読み込みには影響しない

## テスト

（戻ったときに静的ファイルを取り直し、`onloadHdr` が動いた）、不具合そのものを
再現できない。`event.persisted` が偽なら即 return することは、コードを見て
確かめた（TODO-065 の verifier）。

**2026-08-26、利用者が実機のブラウザで、直っていることを確認した。**
