## きっかけ

利用者から、`docs/UsersGuide.md` の冒頭に目次を付けるよう頼まれた。
立てたあとで `docs/Developer.md` も対象に足した。

## やったこと

- `docs/UsersGuide.md`: 前書きと「## 1. 週の表示」の間に「## 目次」を置き、
  `##`（1〜12）と `###`（9.1〜9.5）へリンクした
- `docs/Developer.md`: 前書きと「## 1. 技術スタック」の間に「## 目次」を置き、
  `##`（1〜10）と `###`（10.1〜10.2）へリンクした
- 目次は見出しから Python のスクリプトで作った。リンク先は GitHub の
  見出しのアンカーの規則（小文字にし、文字・数字・`-`・空白以外を除き、
  空白を `-` にする）で作った。見出しの `` ` `` は目次の文言から外した

## 確かめたこと

- `github-slugger`（GitHub と同じアンカーの作り方をする npm パッケージ）で
  両文書の見出しからアンカーを作り、目次のリンクと照合した。
  UsersGuide.md は 17 件、Developer.md は 12 件で、どれも一致し、
  目次から漏れた見出しも無い。`・` や `—` を含む見出し
  （「10.2 JavaScript scroll・size 関連」「9.4 左上のボタン — もっと前を探す」）も一致した
- 先に `gh api /markdown` で GitHub に描画させて照合しようとしたが、
  返る HTML に見出しの `id` が付かなかったので使えなかった

## 残ること

- 見出しを足したり名前を変えたりしたときは、目次も手で直す必要がある
