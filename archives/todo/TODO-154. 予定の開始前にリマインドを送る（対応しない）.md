# TODO-154. 予定の開始前にリマインドを送る（対応しない）

|      | main | 担当 |
|------|------|------|
| 見込み | Sonnet 5 / effort medium | main のみ |
| 実施 | Opus 5 / effort medium | main のみ |

## きっかけ

TODO-153 で、今日の予定と期限の近い ToDo を 1 日 1 回まとめて Slack へ
通知するようにした。ただ、個々の予定の「開始 N 分前」には何も出ない。
開始前のリマインドも欲しかったが、二重に送らないための作りを先に決める
必要があった。決めることは 2 つの案（送信済みの予定 ID を datadir に
残す案と、cron の間隔と揃えて状態を持たない案）に絞ってあり、TODO-153 を
しばらく使ってから選ぶことにしていた。

## やらないと決めた理由

**開始前のリマインドという機能自体が要らないと決めた。**

二重送信をどう避けるかは、リマインドを送るなら決めなければならない話
だった。送らないので、送信済みの記録も、cron の間隔の取り決めも、
時刻の無い予定（`TIME_NULL`）の扱いも、決める必要が無くなった。

通知は TODO-153 の 1 日 1 回のまま（`ytsched notify`、cron の設定例は
`docs/User.md`）。

## テスト

コードを変えていないので無し。
