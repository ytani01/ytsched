# Wording Check (文書語彙確認)

利用者が明示して依頼した場合に、コミットに含まれる `.md` ファイルを対象に、
リポジトリ初出語（前例のない語）を抽出して造語の混入を防ぐ手順。

## 手順

1. **対象ファイルの取得**:
   ```bash
   git diff --cached --name-only -z -- '*.md' | tr '\0' '\n'
   ```
   （未ステージの変更を含める場合は `git diff --name-only -z HEAD -- '*.md' | tr '\0' '\n'`）

2. **語の抽出**:
   対象 `.md` ファイルを読み、専門用語・言い回し・名詞をリストアップする。

3. **前例件数の確認**:
   `HEAD` を基準に各語の出現数を検索する:
   ```bash
   git grep -cF "<語>" HEAD -- '*.md' || true
   ```
   - 一致が 0 件の場合は「前例なし」。

4. **見立ての作成**:
   - 前例なしの語について、一般的な IT 用語か、リポジトリ独自の表現かを見立てる。
   - 語数が 10 語を超える場合は造語の混入を疑う（通常は 1〜3 語程度）。

5. **報告**:
   結果を管理者に提示し、コミット可否の判断を仰ぐ。
